# 🌟 Kawaii Pomodoro — Chrome Extension

A cute and simple Pomodoro timer designed to help you stay focused using work/break cycles, animated stickers, and sound notifications.  
This extension was built with pure HTML, CSS, and JavaScript — no frameworks required.

---

## ✨ Features

- 🎀 **Work & Break modes**  
- ⏱️ **Customizable timer**  
- 🔔 **Sound notifications** (start & end)
- 📩 **Chrome notifications** when time ends  
- 🐣 **Animated kawaii GIF stickers** that change by mode  
- ⏸️ Pause / Resume support  
- 💾 Fully offline — all assets stored locally  
- 🎨 Clean, cute, minimal UI designed for focus
